# Generated website artwork

This directory is the single working location for artwork created with the
`personal-style-thumbs` skill.

Each image lives in its own folder:

```text
<section>/<image-slug>/
  candidate-a.png
  candidate-b.png
  final.webp
  brief.md
```

- `candidate-a.png` and `candidate-b.png` are local review files.
- `final.webp` is created only after the owner chooses A or B.
- `brief.md` records the intended placement, display size, prompts, selection,
  and export details.

Creating a final image here does not authorize importing it into the website,
committing it, publishing it, or deploying it.
