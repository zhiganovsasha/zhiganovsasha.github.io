# Личный сайт

Проект подготовлен для совместной работы через Codex, Google Antigravity и
OpenCode.

## Как устроена работа

- `main` — стабильная ветка.
- `dev` — обычная рабочая ветка. Именно она должна быть открыта во время работы.
- `AGENTS.md` — единые правила для всех агентов и моделей.
- `.agents/skills/` — единственная папка проектных навыков.

Codex, Antigravity и OpenCode читают корневой `AGENTS.md`. Antigravity и
OpenCode также обнаруживают навыки в `.agents/skills`, поэтому отдельные копии
одних и тех же навыков для каждого агента не нужны.

## Документы проекта

- [`docs/PROJECT-SPEC.md`](docs/PROJECT-SPEC.md) — утверждённая спецификация
  сайта и источник правды для всех агентов.
- [`docs/TODO.md`](docs/TODO.md) — задачи, которые сознательно отложены или
  требуют отдельного разрешения.

Спецификация утверждена. Первая локальная реализация сайта создана на Astro
(статическая сборка). Публикация и деплой по-прежнему требуют отдельного
прямого указания владельца.

## Локальный запуск

Внимание: папка проекта находится на виртуальном диске Google Drive, и
`npm install` внутри неё завершается ошибками записи (EBADF). Рабочая копия
с установленными зависимостями живёт на локальном диске:

```powershell
cd "C:\Users\1234\AppData\Local\Temp\opencode\my-personal-website"
npm run dev
```

Сайт откроется на `http://localhost:4321`. Каталог `Temp` может очищаться
системой; если копия пропала, попросите агента пересоздать её из этого
репозитория. Исходники (`src/`, `public/`, конфиги) всегда синхронизируются
обратно в этот репозиторий.

Проверка поведения (модальные окна, меню CV, ссылки, запрет символа `·`):

```powershell
node check-site.mjs
```

Перед началом работы достаточно убедиться, что активна ветка `dev`:

```powershell
git status --short --branch
```

Первая строка должна начинаться с `## dev`.

## Добавление навыка

Каждый навык хранится в отдельной папке:

```text
.agents/skills/<название-навыка>/SKILL.md
```

Не кладите проектные навыки в `.codex/skills` или `.opencode/skills`: это
создаст несколько расходящихся копий.
