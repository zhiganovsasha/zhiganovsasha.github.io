# Спецификация личного сайта Alexander Zhiganov

Статус: утверждено владельцем 23 октября 2026 года.

Этот документ фиксирует результат продуктового интервью. Он является основным
источником правды для Codex, Google Antigravity, OpenCode и других агентов.
Утверждение спецификации не является разрешением начать разработку, создать
публичный репозиторий, выполнить push или опубликовать сайт.

## 1. Цель

Создать персональный сайт Alexander Zhiganov для поиска постоянной,
качественной и хорошо оплачиваемой работы в UAE или удалённо по всему миру.

Главные приоритеты:

1. Быстро запустить достоверную первую версию без лишней сложности.
2. Показать Александра как человека, который соединяет исследование,
   технологии, искусство, идеи и работающие продукты.
3. Доказать компетенции через реальные продукты, процессы и результаты.
4. Не создавать впечатление фрилансера, рекламного специалиста или автора
   мобильных рекламных кампаний.
5. Сохранить возможность перенести сайт с GitHub Pages на обычный домен и
   хостинг без изменения публичных путей.
