# Project skills

Store shared project skills here:

```text
.agents/skills/<skill-name>/SKILL.md
```

Each `SKILL.md` must begin with YAML frontmatter containing at least `name` and
`description`. Keep the folder name and the frontmatter `name` identical.

This directory is shared by Codex, Google Antigravity, and OpenCode. Do not keep
agent-specific copies of the same project skill.
